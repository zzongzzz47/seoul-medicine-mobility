# 서울 폐의약품 배출 이동 부담과 편의점 보완 거점 분석

봉천동 일대와 창신·숭인동을 대상으로 기존 폐의약품 수거망을 유지하면서,
편의점 보완 거점의 입지에 따른 주민의 보행거리 변화를 분석한 코드입니다.
「서울 폐의약품 배출 이동 부담 완화를 위한 편의점 보완 거점 입지 분석」 보고서에 대응합니다.

## 노트북으로 살펴보기

`analysis.ipynb`는 사용자가 직접 수정한 최신 설명과 출력 문구를 반영했습니다.
공개용 파일에서는 원자료 포함 여부 안내를 맞추고 실행 출력을 비웠습니다.
좌표계 변환 및 Python 3.11 문법 수정도 포함되어 있습니다.


- `analysis.ipynb`: 데이터 정제, 공간 연결, 최적화와 시각화의 전체 코드. 출력은 비워 두었습니다.
- `model_check.ipynb`: 원자료 없이 작은 예제 24개로 최적화 구현을 확인합니다.
- `src/`: 각 분석 단계의 코드 파일. `analysis.ipynb`의 구현 셀과 같은 코드입니다.

Jupyter에서 저장소 폴더를 연 뒤 노트북을 실행하세요. 전체 분석에는 `docs/DATA.md`의 입력 자료가 필요합니다.
신청 원자료가 포함된 개인용 데이터 묶음을 공개 저장소에 자동 업로드하지 않습니다.
이 저장소의 `reference/`에는 원본 해시 목록과 보고서 비교용 결과가 있습니다. 원본 인구 자료는 없습니다.

Python 3.11의 f-string 문법과 좌표계 변환 문제를 수정했습니다.
Python 3.11.11에서 모든 소스의 문법과 작은 예제 24개를 확인했습니다.
같은 환경에서 저장된 결과 40개를 재집계하고 지도·그래프 6개를 생성했습니다.
별도 데이터 ZIP과 합친 전체 분석도 Python 3.11.11에서 확인했습니다. 원자료 전처리와 보행거리 계산부터 새로 실행해 기본 40개 모형을 재현했습니다.

## 분석 내용

- SGIS 100m 인구 격자, 집계구 연령 통계와 행정경계를 연결합니다.
- 거주지·기존 수거지·편의점·정류소를 OpenStreetMap 보행망에 연결합니다.
- 집에서 수거지까지 왕복하는 거리와, 가장 가까운 정류소로 이동하며 들르는 추가거리를 계산합니다.
- 기존 수거망을 유지하면서 인구 가중 평균 이동거리를 최소화하는 편의점을 선정합니다.
- 고령층 우선 배치, 점포 불참 대안, 계단 제외와 큰 인구 격자에 대한 민감도를 검토합니다.

수거 가능 품목에 따라 기존 시설의 이용 조건을 구분합니다. `solid`는 전용 수거함과 우체통,
`liquid`는 전용 수거함을 사용합니다. 두 경우의 수요 인구는 같으며, 약품별 발생량을 추정한 것이 아닙니다.
기본 분석은 2개 지역 × 2개 수거 조건 × 2개 이동 상황 × 5개 도입 규모 = 40개입니다.
추가 점포 수는 0·3·5·10·15곳이며 각 규모를 독립적으로 최적화합니다.

## 실행 범위

이 저장소에는 분석·시각화 코드와 실행 설명을 제공합니다. 원자료와 주민 격자별 가공자료는 포함하지 않습니다.
전체 결과를 다시 계산하려면 [데이터 안내](docs/DATA.md)에 따라 입력 자료를 별도로 준비해야 합니다.
입력 자료가 없으면 프로그램은 누락 파일을 알리고 종료하며, 실제 분석 결과를 임의 자료로 대체하지 않습니다.

### 원자료 없이 모형 계산 확인

Python 3.11 이상 환경에서 다음을 실행합니다. Windows에서는 `python`, macOS에서는 환경에 따라 `python3`를 사용합니다.

```text
python -m pip install -r requirements.txt
python src/location_model.py
```

두 번째 명령은 작은 임의 예제 24개에서 최적화 해를 완전탐색 결과와 비교합니다.
`passed: true`는 계산 검증의 통과를 뜻하며 서울시 실자료 분석의 완료를 뜻하지 않습니다.

### 기존 정제 자료로 전체 분석

```text
python run_analysis.py --check
python run_analysis.py
```

첫 명령은 필요한 파일의 존재만 확인합니다. 두 번째 명령은 기본 분석, 확장 분석, 그림 및 HTML 결과를 차례로 만듭니다.
기존 `results/`의 같은 이름 결과를 갱신하므로 이전 실행을 보관하려면 해당 폴더를 먼저 복사하세요.

### 원자료에서 시작

```text
python run_analysis.py --prepare
```

SGIS ZIP과 시설 원자료, 저장된 OSM 자료가 필요합니다. 현재 시점의 OSM 자료를 새로 받으려면
`--download-network` 옵션을 함께 지정합니다. 이 옵션을 지정할 때만 OSM 다운로드를 수행합니다.
새로 받은 도로망과 갱신된 시설·인구 자료는 보고서에 사용한 시점과 달라질 수 있습니다.

지도와 그래프에는 한글 글꼴이 필요합니다. Apple SD Gothic Neo, 맑은 고딕, 나눔고딕,
Noto Sans CJK KR 중 설치된 글꼴을 사용합니다. 글꼴 파일을 직접 지정하려면 `SEOUL_FONT_PATH`를 설정합니다.

## 코드 구성

| 파일 | 역할 |
|---|---|
| `run_analysis.py` | 입력 확인과 실행 순서 관리 |
| `src/extract_convenience.py` | 상가정보 CSV에서 편의점 업종 추출 |
| `src/prepare_inputs.py` | 기존 수거지·우체통·편의점·정류소 정제 |
| `src/prepare_resident_inputs.py` | SGIS 인구·연령·행정경계 연결 |
| `src/fetch_expanded_network.py`, `src/add_network_buffer.py` | OSM 보행망 다운로드와 경계 확장 |
| `src/mobility_network.py` | 보행망 구성·위치 연결·최단거리 계산 |
| `src/location_model.py` | 혼합정수 최적화와 작은 예제 검증 |
| `src/run_resident_analysis.py` | 기본 40개 시나리오 |
| `src/run_resident_extensions.py` | 고령층·점포 불참·민감도 분석 |
| `src/build_resident_report.py` | 결과 재집계 검증, 지도·그래프·HTML 생성 |
| `src/plot_fonts.py` | 한글 글꼴 선택 |

주요 결과는 `results/resident_analysis/summary.json`, `extensions.json`, `validation.json`,
`interpretation_metrics.json`, `figures/`에 생성됩니다. 이 코드는 제출용 Word 편집 파일을 생성하지 않습니다.

## 해석과 재현

계산값은 각 주민이 한 번 배출한다고 가정한 잠재 보행거리입니다. 실제 통행량이나 연간 총절감량이 아닙니다.
정류소 경유는 거주지에서 보행거리상 가장 가까운 정류소를 고정한 상황입니다.
350m는 최적화의 선정 기준이 아니며, 거리별 접근률의 보조 기준으로만 사용합니다.
SGIS 미공개 값과 연령별 비공개 구간은 코드에 명시한 규칙으로 처리합니다.
점포 참여, 수거 가능 시간, 경사에 따른 속도와 운영비는 별도로 확인할 항목입니다.

- [분석 방법과 데이터 처리](docs/METHODS.md)
- [원자료 준비와 출처](docs/DATA.md)
- [공개용 코드 구성과 확인 범위](docs/REPRODUCIBILITY.md)

분석 및 문서·시각화 코드 작성에는 OpenAI Codex를 활용했습니다.
