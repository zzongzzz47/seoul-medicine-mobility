서울 폐의약품 분석: 코드와 데이터를 합쳐 실행하기

1. github_upload_user_edited.zip을 압축 해제합니다.
2. seoul_data_only.zip을 압축 해제합니다.
3. 데이터 ZIP에서 나온 seoul_analysis_data 폴더 안의 data와 results 폴더를
   코드 폴더의 analysis.ipynb와 같은 위치로 옮깁니다.
   seoul_analysis_data 폴더 자체를 코드 폴더 안에 넣는 것이 아닙니다.

최종 폴더 모양
seoul-medicine-mobility/
  analysis.ipynb
  model_check.ipynb
  requirements.txt
  src/
  docs/
  reference/
  data/
    raw/
    processed/
    bundle_manifest.json
  results/
    resident_input_audit.json

4. Jupyter에서 위 코드 폴더의 analysis.ipynb를 열고,
   커널 재시작 후 모든 셀 실행을 선택합니다. Python 3.11 이상을 사용하세요.
5. 첫 셀에서 필요한 패키지가 없다고 나오면 INSTALL_MISSING_PACKAGES = True로
   바꿔 실행합니다. 패키지를 설치할 때만 인터넷 연결이 필요할 수 있습니다.

REBUILD_INPUTS = True: 원자료부터 공간 연결을 다시 수행합니다(기본값).
REBUILD_INPUTS = False: 제공된 정제자료를 사용합니다.
두 설정 모두 최적화 계산을 수행합니다. 처음 실행할 때는 저장된 거리 행렬이
없으므로 보행 경로를 계산하며, 이후에는 입력이 같은 경우 캐시를 재사용합니다.
결과는 results/resident_analysis/에 생성됩니다.

GitHub 웹의 일반 노트북 파일 화면은 코드 열람용입니다.
계산은 Jupyter 등 Python 실행 환경에서 진행합니다.

데이터 ZIP에는 SGIS 신청 원자료와 이를 가공한 공간 자료가 포함됩니다.
본인 보관용 묶음이며, 공개 게시나 타인에게 재제공하기 전에는 제공기관과
신청 당시 이용 조건을 확인하세요. 이 작업은 데이터를 외부에 업로드하지 않습니다.
자료 출처와 기준 시점은 코드 폴더의 docs/DATA_SOURCES.md에 있습니다.
