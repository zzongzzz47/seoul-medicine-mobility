# 공개용 코드와 재현

보고서 분석에 사용한 최종 주민 기준 코드를 공개용 폴더로 복사했습니다.
이전의 시설 격자 기반 예비 분석과 Word 편집용 코드는 포함하지 않습니다.

공개용 구성에서 추가·수정한 내용:

- 실제 사용한 편의점 CSV 추출 규칙을 별도 스크립트로 제공합니다.
- `run_analysis.py`에서 입력 확인·정제·분석·그림 생성 순서를 안내합니다.
- 첫 실행 시 결과 폴더가 자동 생성되도록 수정했습니다.
- 특정 Mac 글꼴 경로를 설치된 한글 글꼴 탐색으로 바꿨습니다.
- 최적화 목적식, 수요 인구 처리, 보행망과 거리 계산은 그대로 유지했습니다.

확인 범위는 `reference/package_checks.json`에 기록합니다.
`--check`는 입력 파일의 존재 확인이며 내용·접근 권한·분석 결과의 타당성 확인을 대체하지 않습니다.
계산 결과의 동률 최적해는 실행 환경에 따라 점포 조합이 달라질 수 있으므로 목표값도 함께 비교합니다.

원자료는 공개용 ZIP에 포함하지 않았습니다. 전체 분석 재현에는 `docs/DATA.md`의 자료가 필요합니다.
보고서 당시 자료의 파일명과 해시는 `reference/input_checksums.json`과 `reference/osm_manifest.json`에 남겼습니다.
이 파일들은 원자료가 아닌 출처·버전 확인용 목록입니다.
