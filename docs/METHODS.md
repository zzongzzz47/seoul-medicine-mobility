# 분석 방법

## 공간 범위와 인구

봉천동 일대: 보라매동·청림동·성현동·행운동·낙성대동·청룡동·은천동·중앙동·인헌동.
창신·숭인동: 창신1·2·3동, 숭인1·2동.
100m 격자 중심이 대상 행정동 안에 있는 격자를 선택합니다.
65세 이상 인구는 집계구 내부 대표점으로 유지하며 100m 격자로 임의 배분하지 않습니다.
인구 미공개 격자를 0명으로 치환하지 않습니다. 연령 구간의 비공개 값은 0~4명 범위와
총인구를 사용해 하한·상한을 계산합니다. 보고서의 연결 인구는 봉천동 223,164명, 창신·숭인동 36,036명입니다.

## 보행거리

EPSG:5179에서 거리를 계산합니다. OSM 보행 금지·사유 접근 도로를 제외하고
공유 노드로 연결된 길을 사용합니다. 지점과 도로 구간 사이의 연결 거리가 80m를 넘으면 연결하지 않습니다.
격자 중심·시설에서 도로까지의 연결 거리도 경로 비용에 포함합니다.
지도 경계 바깥을 통과하는 더 짧은 경로의 가능성은 거리 하한으로 점검합니다.

- 왕복거리: `d(거주지, 수거지) + d(수거지, 거주지)`
- 정류소 경유거리: `d(거주지, 수거지) + d(수거지, 정류소) - d(거주지, 정류소)`

정류소는 거주지마다 보행거리상 가장 가까운 한 곳으로 고정합니다.
실제 주민별 목적지·통행 경로를 관측한 것이 아닙니다.

## 최적화

주민 i의 기존 최소 거리 b_i, 후보 j 이용 거리 c_ij, 공개 인구 w_i를 사용합니다.
후보 선택 변수 x_j가 1인 점포 중 가장 가까운 곳과 기존 수거망을 비교합니다.
목표는 `sum_i w_i × min(b_i, min_{j:x_j=1} c_ij)`의 최소화이며 `sum_j x_j <= K`를 제약으로 둡니다.
코드에서는 점포 선택의 이진변수와 시설 배정변수로 선형화합니다. 같은 주민의 혜택을 중복 합산하지 않습니다.
SciPy의 `milp`와 HiGHS를 사용하고 상대 최적성 허용 오차는 1e-7입니다.

고령층 우선안은 전체 주민의 거리 감소를 효율안 대비 90%·95%·100% 이상 유지하면서
고령인구 가중 평균 거리를 최소화합니다. 95%는 비교를 위한 정책 조건입니다.
하나의 점포가 불참하면 나머지 점포를 고정한 채 대체 후보를 찾습니다.
계단 민감도는 OSM에 계단으로 표시된 구간을 제외한 결과이며 무장애 경로를 인증하는 분석은 아닙니다.
